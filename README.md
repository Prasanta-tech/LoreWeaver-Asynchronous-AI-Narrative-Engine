
# LoreWeaver
### Asynchronous AI Narrative Engine

An AI-powered narrative generation platform designed to create and manage structured stories through an asynchronous processing workflow.

---

## Overview

LoreWeaver explores the use of AI in interactive storytelling. It provides an application interface for generating narratives while separating user interactions from the underlying processing workflow.

The project is organized into frontend and backend components, with the goal of maintaining a modular structure that can be extended with additional narrative-generation capabilities.

## Features

- **AI-powered narrative generation** — Generate story content using an AI-driven workflow.
- **Asynchronous processing** — Handle longer-running generation tasks without unnecessarily blocking user interactions.
- **Frontend integration** — Provide an interface for interacting with the narrative engine.
- **Modular architecture** — Keep application components organized for easier maintenance and future development.
